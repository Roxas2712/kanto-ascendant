# Blue battle-back source note

FireRed/LeafGreen does not contain an official playable Blue back picture.
Blue's optional **CRYSTAL CHARS** 2D battle back is therefore an original
Kanto Ascendant five-frame FRLG-style adaptation, authored as a large
shoulder/upper-torso sequence matching the shared Red/Casey framing.

Blue's current 2D front is the Kanto Ascendant adaptation retained with the
project-authored back sequence. Voxel uses separate custom 128×128 standing
art and never the 2D upper-body back; the player-side front card is mirrored
so both trainers face one another.

The five runtime PNGs are hard-edged native 64×64 images with one shared
palette and baseline. They do not reuse or redistribute the earlier community
Blue backsprite candidate.
