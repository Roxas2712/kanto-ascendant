# Hidden Evolution: RED, BLUE and GREEN solution maps

> **Full gameplay spoilers:** these guides reveal every fissure location,
> mandatory puzzle, Mega Stone cache and final-door requirement for Kanto
> Ascendant 6.5.3.

[Open the offline HTML guide](index.html)

The guide is written in German and contains an overview plus separate RED,
BLUE and GREEN pages. Every stylesheet, script and image is stored in this
directory, so the guide works without an internet connection: download this
directory, then open `index.html` in a browser.

- [RED / Groudon / fire path](red.html)
- [BLUE / Kyogre / water path](blue.html)
- [GREEN / Rayquaza / grass path](green.html)

The maps distinguish mandatory grey quiz statues from optional yellow floor
lights. Quiz order and answer position are save-bound and shuffled; the maps
therefore document the route and required interactions, not a reusable answer
button sequence.
