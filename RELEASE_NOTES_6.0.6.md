# Kanto Ascendant 6.0.6 — New Game+ Steward Hotfix

Version 6.0.6 is a save-compatible hotfix for the Ascendant Cycle / New
Game+ handoff.

## Fixed

- The Ascendant Steward now appears in the reachable **Indigo Plateau Lobby**
  when New Game+ is ready.
- The Steward no longer spawns on the Hall of Fame's one-way Champion
  cutscene map, where a completed post-game save could not reach them.
- The Research Atlas, README and spoiler FAQ now identify the Indigo Plateau
  Lobby as the New Game+ location.

## Compatibility and saves

- Pokémon Red, Blue and Yellow.
- English and German.
- Existing Kanto Ascendant 6.0.x saves; no migration is required.
- Existing completion, party, inventory, legends, titles and cycle progress
  remain unchanged.

## Verification

- Full ROM-free regression suite, including a New Game+ Steward location
  assertion.
- Strict Modkit validation and reproducible package inspection.
