# Mira

`mira_walk.png` is Mira's unique native, palette-aware 16×96 walker strip:
stand down/up/left, walk down/up/left. Right-facing frames are mirrored by the
engine. The sprite is registered as `SPRITE_KA_MIRA_WALK`; it never changes the
shared female Cooltrainer definition.

Art: generated with OpenAI's built-in image_gen on 2026-09-25 for this project.
Identity: asymmetrical bob and tuft, neckerchief, short field jacket, boots and
crossbody pouch. The native asset uses three grayscale shades and real alpha.
The VASC companion provides matching HD and voxel 4×3 atlases under the role
`mira`; KASC remains usable without VASC.
