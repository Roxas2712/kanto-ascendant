# KASC 6.7.24 — Ascendant menu organization

Full public test update, published as a regular release for launcher updater compatibility.

## Changes since 6.7.23
- Reorganized the Ascendant menu: unlocked gameplay groups first, followed by Settings, Voxel Ascendant, Your Look and DLC / Sprites when available.
- Moved Errors and Diagnostics to the support area near the bottom. Opening a report, its unread count and existing feature unlocks remain available.
- Based on the complete public 6.7.23 release, retaining its Legacy Bank NG+ ownership safeguards and automatic repair when stored handoff evidence proves that old-run leases are obsolete.

The 6.7.23 Bank correction is included; it is not a new Bank change in 6.7.24. No manual replacement of a player's Bank file is required for the proven case.

## Validation
Native combined KASC/VASC menu opening, scrolling, submenu entry/back and error-report access checked. The integrated Bank ownership/recovery regression passes 2,007 assertions. Complete package syntax, integrity and preserving installation checked; see QA-REPORT.md.

Tested on macOS / LÖVE 11.5. This is a test release; physical mobile and full Windows campaign verification remain pending.

## Installation
Back up the save folder including mod_storage, close the game, install the complete Kanto-Ascendant-6.7.24.zip through the launcher and restart. Existing saves and optional artwork are retained. No engine, ROM or player save is included.
